# Odin Project: Etch A Sketch

## What is it?
This is one of the projects from The Odin Project's Foundation Course. This is a browser version of something between a sketchpad and an Etch-A-Sketch.

## My learnings from this project
- utilization of event bubbling for efficiency
- removal of all children elements from parent
- usage of a for loop to alter all children
- add tooltips for button hints
- usage of target events to change specific child elements
